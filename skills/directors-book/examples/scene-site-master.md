# 示例：场景母版提示词（工地宿舍区）

> 状态：作者出过一版成图，反馈「布局对了，但锐化过度、一眼 AI」，按反馈改成下面这版，**第二版成图作者还没有反馈**，效果未验证。
> 结构见 `references/asset-scene.md`。

```
【版式与媒介】真实电影摄影机拍摄的电影剧照，写实，不是 CG、不是游戏原画、不是概念图、不是 AI 插画。横屏16:9（画幅按用户选择填写）。场景母版：纯场景，画面里没有任何人物和人影，图上没有任何文字。主机位A：摄影机站在空地中央偏后的位置，面朝板房宿舍与脚手架的方向，镜头离地约1.5米，平视，焦距感接近40mm，透视自然，不做超广角的夸张变形。

【场景总设定】外地一处建筑工地的工人宿舍区，傍晚收工之后，天色偏灰，夕阳只剩一点余光。画面安静，没有人，也没有机器在运转。空气里有很淡的细灰。

【空间分层】前景：压实的干泥土空地，地面微潮但不积水，只有一两块红砖和几处极浅的水泥粉痕，不要钢筋头，不要碎石特写；前景只占画面下缘。中景：画面右侧是一排单层彩钢板房宿舍，淡蓝灰色板面，边缘和门框有少量锈迹，板房门前有两级水泥台阶，台阶边缘有轻微磕损，门是一扇旧的绿色铁皮门，门旁有一扇小窗，窗里透出一点暖黄色灯光。画面左侧背景是一座三层高的钢管脚手架，罩着褪色的灰绿色安全网，网面基本完整，只有一两处轻微松垂。远景：画面最深处有塔吊和未完工楼体的灰色剪影，比近处明显柔和，被薄灰遮住。空间布局固定：脚手架在画面左侧的背景里，板房宿舍在画面右侧，台阶在板房门前，台阶前是一片开阔的空地。以上左右关系均以主机位A的画面为准。

【光影】天色以冷灰色的云层为主，云层平淡，没有戏剧性的彩云。夕阳只在远处地平线留下一小块暖色，整体光线是冷灰色的柔和漫射光，阴影软、不死黑。钢管和板房的边缘不要出现亮橙色的轮廓光；暖色只出现在地平线附近和窗内的灯光里。窗里那一点暖黄灯光是唯一的人造光，很弱。不允许出现没有来源的光。

【色彩与材质】低饱和，以冷灰、灰蓝、旧铁锈的暗红褐和泥土的灰褐色为主。安全网是褪色的灰绿，不是鲜艳的青绿；暖金色只占地平线一小块；不要青橙对比色调。材质写得克制：彩钢板有少量锈迹和轻微凹痕，水泥台阶是哑光灰色并有轻微磕损，钢管是旧镀锌的灰色。细节密度中等偏低，不逐个刻画每块砖、每粒碎石。整体是用旧了的工地，不是脏乱破败。

【镜头质感】电影剧照质感，低对比，暗部抬起但不死黑，亮部自然滚降，细颗粒胶片感。保留轻微的光学柔化：近处清晰，中景略软，远景（塔吊、楼体、地平线）明显偏软，不要和近处一样锐利。整体中等锐度，不做边缘增强，不做局部对比度增强，没有 HDR 感。

【反向限制】以下内容一律不要出现：人物、人影、文字、招牌上的可读文字或乱码、logo、水印、过度锐化、HDR 感、局部对比度增强、青橙对比色调、物体边缘的亮橙色轮廓光、高饱和、CG 感、概念图感、游戏原画感、插画、没有来源的发光、画面杂乱。
```
