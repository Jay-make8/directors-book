# 示例：场景走位图提示词（工地宿舍区，老周走向台阶）

> 状态：**草案，没有出图验证。** 走位图是线稿示意图，用于让分镜里的走位和机位有一张共同的参考。
> 结构见 `references/asset-scene.md`。对应 `video-prompt-laozhou.md` 的镜头 1。

```
【版式与媒介】根据@图1（场景母版）绘制这个场景的俯视走位图。一张俯视平面示意图，简洁的线稿风格，浅色底，不是写实渲染，不是照片。横屏16:9。图上只用简单符号、字母和箭头标注，文字尽量少。

【方向与固定物】画面上方是脚手架所在的一侧，画面右侧是板房宿舍。板房是画面右侧一条竖长的矩形，门开在朝向空地的一面，门前画两级台阶。画面左上是三层脚手架，用方框表示。中间是开阔的空地。这些位置与场景空间布局一致：脚手架在左侧背景，板房在右侧，台阶在板房门前。

【人物走位】用字母 A 表示老周。起点在脚手架下（画面左上），沿着空地向右走到板房门前的台阶，用一条带箭头的实线表示；终点在台阶上，用一个小圆圈标出「坐下」。沿线标出大致步数。

【机位】标出摄影机位置和朝向，用小三角表示朝向：V1（主机位）在空地中央偏下，朝向右上（面朝板房与脚手架）；镜头1的平移路线用一条虚线箭头表示，与老周的路线平行，向右移动；场景多机位的另外三个机位 V2、V3、V4 各画一个小三角，并标上标签。

【说明】图下用一行小字注明：这是设计示意图，不是实测的建筑图。

【反向限制】以下内容一律不要出现：写实渲染、照片质感、人物的具体长相、大段文字、水印、logo、杂乱的装饰。
```
