# 示例：场景走位图提示词（工地宿舍区，老周走向台阶）

> 状态：**草案，没有出图验证。** 走位图是在俯视平面图（`scene-site-plan.md`）上加画人物路线的线稿示意图，用于让分镜里的走位和机位有一张共同的参考；生成时上传母版（@图1）和俯视平面图（@图2）。
> 结构见 `references/asset-scene.md`。对应 `video-prompt-laozhou.md` 的镜头 1。

```
【版式与媒介】根据@图2（俯视平面图）绘制这个场景的俯视走位图，墙体、固定物和 V1–V4 机位保持和@图2完全一致；@图1（场景母版）只用来对照空间。一张俯视平面示意图，简洁的线稿风格，浅色底，不是写实渲染，不是照片。横屏16:9。图上只用简单符号、字母和箭头标注，文字尽量少。

【保留】方向、板房、台阶、脚手架和 V1–V4 四个机位箭头都和@图2一样，不移动、不重画。

【人物走位】用字母 A 表示老周。起点在脚手架下（画面左上），沿着空地向右走到板房门前的台阶，用一条带箭头的实线表示；终点在台阶上，用一个小圆圈标出「坐下」。沿线标出大致步数。

【镜头路线】镜头1的平移路线用一条虚线箭头表示，从 V1 附近出发，与老周的路线平行，向右移动。

【说明】图下用一行小字注明：这是设计示意图，不是实测的建筑图。

【反向限制】以下内容一律不要出现：写实渲染、照片质感、人物的具体长相、大段文字、水印、logo、杂乱的装饰。
```
