# 示例：视频提示词（老周接电话，15 秒）

> 状态：演示格式用，**未经出图验证**。台词和画面细节是虚构的。
> 格式见 `references/video-prompt.md`。这个例子没有加【摄影与影调】（短剧默认不加）。

```
【整体概念】
工人老周在外地的工地上干了一年，今天傍晚收工后，女儿从老家打来电话。老周想让女儿放心，不愿让她听出自己累，也不敢轻易答应过年回不回去。场景：傍晚的工地宿舍区，天色偏灰，夕阳只剩一点余光。空间布局：脚手架在画面左侧的背景里，板房宿舍在画面右侧，板房门前有两级水泥台阶，台阶前是一片空地。

【参考素材绑定】
角色：老周@图1
场景：主图@图2，多机位@图3，人物走位@图4

【分镜】
镜头1｜外景｜0-5秒｜中全景
镜头在老周侧后方，与他同速向画面右侧平移跟拍。老周从画面左侧的脚手架下出发，沿着空地向画面右侧的板房走去，步子慢而沉，肩膀微微前塌，右手从裤兜里摸出手机，屏幕亮起，他停了半步。他走到板房门前的台阶，转身坐下，把手机贴到耳边；老周坐下的瞬间，镜头停止平移，轻微推近。女儿（期待，手机里）的声音很小，从听筒里传出：“爸，你吃饭了没？”老周（硬撑笑意，声音放轻）肩膀先松下来一点，嘴角硬撑出一个笑，说：“吃……吃过了。”

镜头2｜外景｜5-10秒｜近景
镜头固定在老周的左前方，近景，老周占画面中间，脸朝画面左侧。他的眼睛先收紧，眉间随后皱起，最后嘴唇才抿住，下巴绷紧。眼眶泛红，泪被锁在眼睑边缘，喉结滚动了一次。他嘴角被拉向右侧一点，像在笑，眼睛却往下沉，这个表情很难用一句话说清，辅助校准：AU12 单侧嘴角轻微上提，AU15 嘴角下压，AU1 眉毛内侧上提。女儿（试探，手机里）说：“那你过年回来不？妈说你忙——”老周（抢话）说：“回——”，和女儿最后两个字重叠约0.3秒，随后停了一秒，喉咙里挤出重复的字：“回，回……肯定回。”

镜头3｜外景｜10-15秒｜近景
镜头保持在老周的左前方。女儿（放轻，手机里）说：“那我数着日子啊。”老周的眼睛先垂下，头随后低下，肩膀最后塌下去。他右眼一滴泪划过脸颊，左眼的泪慢半拍才落下，下巴收紧，没有哭出声，只有胸口起伏了一下。他把手机从耳边挪开一点，用手背抹过右脸，再把手机贴回耳边，老周（压着哽咽，声音沙哑）说：“……好，爸，爸也数着。”老周低头时，镜头缓慢拉远，把他身后夕阳下的脚手架收进画面，他在画面里变小。

【声音】
只有真实的工地傍晚环境声：远处机械低沉的轰鸣，风声，脚手架金属偶尔的轻响。无配乐。人物近声：老周沉重的脚步声，衣料摩擦声，压着的呼吸声。女儿的声音从手机听筒里传出，音量小，略带电流质感。

【反向限制】
以下内容一律不要出现：配乐、字幕、夸张的哭喊、面部僵硬、嘴唇无故动作、换脸、服装变化、年龄变化、显老、可读的文字或乱码、水印、运动方向反转、人物瞬移、人物左右位置互换。
```
