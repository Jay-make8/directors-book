# 示例：场景俯视平面图提示词（工地宿舍区）

> 状态：**草案，没有出图验证。** 生成时只上传母版（@图1）。生成后用来生成场景多机位、走位图和核对调度底稿；常规场景也上传给视频模型（复杂场景改传走位图）。
> 结构见 `references/asset-scene.md`。机位和 `scene-site-multicam.md` 的机位清单一致。

```
【版式与媒介】根据@图1（场景母版）生成这个空间的俯视平面图。正上方垂直俯视，简洁的平面示意，不是写实渲染，不是照片：浅色底，墙体用深色粗线，板房、台阶、脚手架用简单的块面和轮廓表示，可以用很淡的颜色区分材质（彩钢板、水泥、泥土地面）。横屏16:9。纯场景，没有人物。

【方向】画面下方是主机位A所在的一侧（空地靠近镜头的一端），画面上方是主机位A朝向的远处；母版里在画面左侧的东西，平面图里也画在左侧。

【空间内容】空间布局：脚手架在画面左侧的背景里，板房宿舍在画面右侧，台阶在板房门前，台阶前是一片开阔的空地。平面上：画面左上是三层脚手架，用一个方框表示；画面右侧是一排单层板房，画成竖长的矩形，门开在朝向空地的一面，门前画两级台阶，门旁一扇小窗；中间是开阔的空地。母版里看不到的板房背面和脚手架后方，只用虚线画大致轮廓。

【机位标注】用小箭头标出四个机位的位置和朝向，每个箭头旁只写一个小号标签：V1 在空地中央偏下，朝画面上方（面朝板房与脚手架）；V2 在板房门前的台阶旁，朝画面左上（面朝空地和远处的脚手架）；V3 在板房靠画面下方的一端，沿板房的长度方向朝画面上方；V4 在空地上离台阶较近处，朝画面右侧（面朝台阶和铁皮门）。不写其他文字。

【反向限制】以下内容一律不要出现：人物、人影、写实渲染、照片质感、透视变形、V1至V4之外的文字、母版里没有的房间或家具、水印、logo、杂乱的装饰。
```
