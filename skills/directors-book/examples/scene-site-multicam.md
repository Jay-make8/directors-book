# 示例：场景多机位提示词（工地宿舍区，两个角度）

> 状态：写法在《雨夜修表匠》钟表铺上实测过一轮（2026-11-02，只传俯视图，四格一致性好；写清摄影机背对什么、什么不入画以后，门口往里看的角度也出来了）；**这个工地场景没有出图验证**。
> 生成时只上传俯视图（@图1，见 `scene-site-plan.md`）。角度按分镜需要出：这里演示两个母版里看不到的方向（从台阶回望空地、沿板房长边看），所以是左右两格。
> 结构见 `references/asset-scene.md`「场景多机位」。

```
根据@图1（这个场景的俯视图）生成同一个工地宿舍区的两个平视机位。只生成一张图，左右两格，共 2 格，不多不少；格子位置固定：V1在左、V2在右。空间布局、板房、台阶、脚手架的位置大小形状、材质和光线全部以@图1为准，两格是同一时刻的同一个空间，不新增、不删除、不移动任何东西。纯场景，没有人物。

V1：摄影机在板房门前的台阶旁，背对板房的铁皮门，朝空地和远处的脚手架拍；画面最近处是台阶的水泥边缘，中间是空地，远处是罩着灰绿色安全网的脚手架；板房不入画。
V2：摄影机在板房离脚手架最远的那一端，沿着板房的长边朝脚手架方向拍；画面右侧是一排板房的门窗往远处延伸，左侧是空地，远处是脚手架和塔吊的剪影。

统一平视，离地约 1.5 米，焦距感接近 40mm，曝光和白平衡一致。每格左上角只标一个小号标签：左格标 V1，右格标 V2，图上不要其他文字。

以下内容一律不要出现：人物、人影、第 3 格、拆成多张散图、两格内容不一致、俯视角度、V1和V2之外的文字、水印、logo。
```

交付说明里附的《机位对照表》（给用户看，不进提示词）：

| 标签 | 摄影机在哪、朝哪拍 | 用于 |
|---|---|---|
| V1 | 板房门前台阶旁，背对板房门，朝空地和脚手架 | 演示用（反打方向） |
| V2 | 板房离脚手架最远的一端，沿板房长边朝脚手架 | 演示用（侧向） |
