# 示例：场景多机位提示词（工地宿舍区）

> 状态：**草案，没有出图验证。** 用在和 `scene-site-master.md` 同一个场景上。
> 结构见 `references/asset-scene.md`。

```
【版式与媒介】根据@图1（场景母版）生成同一个场景的四个机位。只生成一张图，2×2 四宫格，共 4 格，不多不少，不得出现第 5 格，不得拆成多张散图。四格是同一个工地宿舍区在同一时刻的四个机位。纯场景，画面里没有任何人物和人影。

【空间锁定】四格共享同一套布局、板房、脚手架、台阶、地面、材质、光照方向、时段和天气，完全一致。只有摄影机的位置、朝向和取景不同。禁止新增、删除或移动任何物体，禁止把不同空间画进同一张图。空间布局：以主机位A（第1格）的画面为准，脚手架在左侧背景里，板房宿舍在右侧，台阶在板房门前，台阶前是一片开阔的空地。

【机位清单】
第1格｜主机位A｜摄影机在空地中央偏后，面朝板房与脚手架，离地约1.5米，平视｜与母版一致，看清整体布局
第2格｜反向全场｜摄影机站在板房门前台阶旁，面朝空地和远处的脚手架，离地约1.5米，平视｜看清空地的纵深和脚手架的位置
第3格｜侧向全景｜摄影机站在板房一端，沿板房的长度方向朝远处看，离地约1.5米，平视｜看清整排板房的延伸方向和门窗位置
第4格｜入口近景｜摄影机站在空地上，面朝板房门前的台阶和铁皮门，离地约1.5米，平视，距离较近｜看清台阶、门和小窗的细节

【摄影机参数】统一焦距感接近40mm，统一景深，统一曝光和白平衡，透视自然，不做超广角变形。

【影调】影调、光和色调以@图1（场景母版）为准：冷灰色柔和漫射光，暖色只在地平线和窗内灯光里，不要物体边缘的亮橙色轮廓光，近处清晰、远处偏软，不做边缘增强。

【标注】每格只用小号阿拉伯数字1到4标注，图外另附《编号—机位对照表》。图上不要其他文字。

【反向限制】以下内容一律不要出现：人物、人影、文字、logo、水印、第5格、拆成多张散图、四格内容不一致、过度锐化、HDR 感、局部对比度增强、青橙对比色调、物体边缘的亮橙色轮廓光、高饱和、CG 感、概念图感、游戏原画感、插画、没有来源的发光、画面杂乱。
```
