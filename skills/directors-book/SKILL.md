# 导演手册（directors-book）

把一个想法一步步变成可以直接复制使用的文本：剧本、分镜、人物与场景的出图提示词、视频提示词，也可以整合成一个 HTML 导演手册。

## 四个阶段，每个都能单选

| 阶段 | 产出 |
|---|---|
| 剧本 | 短剧或影视剧本，统一的交接结构 |
| 分镜 | 镜头速览表、镜头正文（含镜头标题行）和片段划分表 |
| 资产包 | 人物提示词（人物四视图）、场景提示词（母版、场景多机位、走位图） |
| 视频提示词 | 每个片段一份提示词 |
| **导演手册** | 上面四个阶段全做，交付一个 HTML（剧本、分镜、资产提示词、视频提示词） |

用户可以带上一阶段的成果直接开始（例如直接给分镜，只要视频提示词）。不要重做用户已经给出的阶段。

## 硬规则（每次都遵守，细节在对应文件里）

1. **术语配可见画面**：每个术语和情绪词后面都要有画面里看得见的东西；每句话问「这能被画出来吗」。→ `references/principles.md`
2. **一个镜头不跨片段拆**：片段只在镜头边界断开。→ `references/storyboard.md`
3. **台词原文从分镜起只在【分镜】里写一次**：剧本是源头，不算；速览表、【声音】、资产里都不重复，只引用。
4. **开始前先问**：体裁 → 画幅 → 模型版本，按任务取舍（表和细节见 `references/ask-before-start.md`）。体裁用户没明说就必须问，带了剧本、只给梗概都一样，不能自己推断；只做资产包时不问。用户给的只是故事梗概，不算带了剧本。
5. **资产按编号复用**：同一个人物或场景只出一份完整提示词，其他地方用编号引用，不重写。
6. **剧本不写摄影机**：不写镜头术语，分镜才管怎么拍。
7. **空间布局只定义一次**（门、家具在画面哪一侧，在场景资产里写成一句，以主机位为准）：后面各处**原样复制**这一句，不改写，也不写「沿用」。
8. **不写「变形宽银幕」，不用片名、人名、摄影师名当锚点**。
9. **默认无配乐**，用户要才加。
10. **反向限制必写**：图像用图像底，视频用视频底，用「以下内容一律不要出现」开头。
11. **用户的明确要求优先于这里的默认写法**；时长、图片数量等数字按 `references/models.md`，用户可以覆盖。
12. **交付前过自检**：读 `references/checklist.md` 对应小节，缺项补齐再交付。
13. **用户确认过的剧本、分镜不擅自改**：发现矛盾、错字、措辞问题，先告诉用户、等同意再改；改了的每一处都如实说。前后矛盾（穿戴、道具、外观）要在交付前查出来。→ `references/principles.md` 第 9、10 条
14. **提问优先用弹窗**：向用户提任何问题（开始前先问、确认剧本、确认分镜并选下一步（同一个问题）、发现矛盾要不要改）都优先用环境里的提问选择工具，一次问完、每项都能自己输入；没有这类工具才用文字。→ `references/ask-before-start.md`
15. **先读懂场景，再按剧本的逻辑写调度**：每个动作在场景图里要有走得通的路线，每个机位在参考图里要拍得到；人和关键物品的相对位置跨镜头不变；镜头不去参考图里看不到的区域。→ `references/principles.md` 第 12 条、`references/camera.md` 基础第 15–17 条

## 开始前先问

读 `references/ask-before-start.md`。顺序是**体裁 → 画幅 → 模型版本**，按任务跳过用不到的：只要剧本时不问画幅和版本；带了剧本也要问体裁（体裁影响分镜和视频提示词的摄影规则，手册里也要填），只做资产包时不问；已经说过的不重复问。用户只给了主题、没有人物和事件时，先给 2–3 个核心想法让他选，不要直接写完整剧本，也不要问「要不要生成剧本」。

## 每个阶段交付时必须有

- **剧本**：统一交接结构（人物信息表、场景信息表、场次；每场有动作节拍、台词带语气、结尾状态）。
- **分镜**：每个镜头有标题行（`镜头1｜内景｜0-5秒｜中景`）加正文；一张镜头速览表（景别、机位与运动、画面要点、台词、时间）；一张片段划分表（段落、场景、镜头、总时长、需要的参考图）。
- **资产包**：每个人物一份人物四视图提示词；每个场景按需要的档位出母版、场景多机位、走位图；一张资产编号表。
- **视频提示词**：每个片段一份，五个块齐全（影视体裁可再加【摄影与影调】）。
- **导演手册**：按 `handbook-html.md` 生成 HTML。

缺任何一项，说明没读全，回头补。

## 导演手册的流程

1. 用户给剧本，或让你先写剧本；体裁、画幅、模型版本一起问（带剧本也问体裁）。
2. **先出分镜**。剧本交付后用弹窗问「剧本需要修改吗」；分镜交付后**用一个弹窗一次问完**「分镜需要修改吗，接下来做什么」（不改，生成导演手册；不改，只要提示词；不改，到分镜为止；我要修改）。**弹出这个问题是交付分镜的最后一步，不能在交付后直接结束。**
3. 用户选了下一步就照做，不再另问。导演手册还是只要提示词，每次都要问，**不要在开头问**；用户说「继续做资产和视频提示词」不等于不要手册。开头就说了要完整导演手册的，不再问。
4. 依次完成资产包、视频提示词，整理成 `handbook.json`（内容必须和用户确认过的剧本、分镜一致），运行 `scripts/build_handbook.py` 生成一个 HTML：版式是剧本 → 分镜 → 资产提示词 → 视频提示词（第一段、第二段……放在最后），提示词都可以一键复制。**不要手写 HTML**，字段和降级办法见 `references/handbook-html.md`。

## 边界

- 本 skill 只产出文字提示词和 HTML 文件，**不调用任何生成服务，不上传素材**。
- 这里的大多数写法来自对其他 skill、教程和实际出图反馈的整理，**没有做过系统的对照实验**。遇到效果不好，先按 `principles.md` 的「出错只改出错的那一层」排查，并如实告诉用户哪些写法是默认的、没有在他的平台上验证过。
