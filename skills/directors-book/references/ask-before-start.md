# 提问规则

分两节：**第一节「开始前先问」**收集体裁、时长（要写剧本时）、画幅、模型版本；**第二节「流程中的确认」**是每个阶段交付后、以及几种特定情况下必须提的问题。所有提问的完整规则只写在这份文件里，其他文件只引用（唯一例外：要不要安装 Python 那一问的细节和安装命令在 `handbook-html.md`）。

**先看这几条（优先级最高）：**

1. **所有提问优先用提问器（弹窗）**，每个问题带选项，选项下面用户都能自己输入；环境里没有提问器才用文字列出选项。有提问器却用文字列选项，不算问了。
2. **开始前用一个弹窗问完，顺序是体裁 → 时长 → 画幅 → 模型版本**；时长只在要由你来写剧本时问，选项是「按剧情估一个（推荐）」「先看方向再定」，不写秒数，用户要自己定就在输入框里填。
3. **每一次新的生成请求都重新问**（同一个对话里前面问过也一样），每个问题把上次的选择排第一个、标「（上次）」；只有接着做同一份作品的下一阶段才沿用。
4. **每个阶段交付的最后一步是确认问题，问完停下等回答**，不替用户选（第二节）。
5. 生成 HTML 找不到 Python 时，也用提问器问要不要安装，写明不装的后果，同意才装（`handbook-html.md`）。

## 第一节　开始前先问

### 顺序

**体裁 → 时长 → 画幅 → 模型版本**：先定故事（拍成什么、多长），再定制作（画幅、模型）。时长只在要由你来写剧本时问（见下面「时长」）。只问当前任务需要的，放进同一个弹窗。

| 任务 | 体裁 | 时长 | 画幅 | 模型版本 |
|---|---|---|---|---|
| 只要剧本（要你来写） | 问 | 问 | 不问 | 不问 |
| 只要剧本（用户已带剧本，只是改） | 问（带剧本也问） | 不问 | 不问 | 不问 |
| 分镜 | 问（带剧本也问） | 没有成稿剧本、要先写剧本时问 | 问 | 问 |
| 资产包 | 不问 | 不问 | 问 | 问 |
| 视频提示词 | 问 | 不问 | 问 | 问 |
| 导演手册 | 问（带剧本也问） | 没有成稿剧本、要先写剧本时问 | 问 | 问 |

**沿用的范围只到这一份作品**：接着做同一份作品的下一个阶段（剧本做完接着出分镜、分镜确认后接着做资产），问过的沿用，不再问。**每一次新的生成请求都重新问**，即使在同一个对话里、前面已经问过：用户换了一个故事或主题，或者要再做一份新的剧本、分镜、导演手册（包括「再生成一份」「重新做」），都算新的请求。上一次选的是短剧，这一次可能要影视。

重新问时，每个问题把上次的选择排在第一个并标上「（上次）」，例如体裁的选项是「短剧（上次）」「影视」，画幅是「竖屏 9:16（上次）」「横屏 16:9」，用户照旧点第一个就行，想换也能直接换。只有用户在这一次请求里明说了（「还是短剧竖屏 2.5」「和上次一样」），才不问。

**先判断用户给的是什么：**

- 用户给的是**故事梗概、想法或几句话的情节**，这**不是剧本**。任务要从剧本阶段开始。成稿剧本（有场次、动作、台词）才算「用户已带剧本」，但**带了成稿剧本也要问体裁**：体裁决定分镜和视频提示词用哪一套摄影规则，手册里也要填。不要因为故事已经有了，就当成只剩分镜或视频提示词。
- **体裁不能自己推断**：用户没明说「短剧」或「影视」时（带了剧本也一样），不要根据故事内容、时长、风格猜体裁，必须问。只做资产包时不问。
- **开头不问「做到哪一步」**：用户没说做到哪一步时，从他给的东西对应的阶段开始（只有故事，就从剧本开始），每个阶段交付后用第二节的确认问题带他往下走。要不要手册、还是只要提示词，**交付分镜时和确认分镜一起问**。

### 怎么问

开始前要问的几项（体裁、时长、画幅、模型版本，按任务取舍）**放在一次里问完，按上面的顺序**，让用户一次回答，不要拆成好几轮。

**有提问选择工具（弹窗选项）就用它，没有就用文字。**

- 把需要问的几项放进**同一次调用**，顺序是体裁 → 时长 → 画幅 → 模型版本；只放当前任务需要的。
- 每一项都必须允许用户**自己输入**（例如「其他」）；工具不允许自由输入，或一次只能问一项，就改用下面的文字问法。
- 选项如下：

| 问题 | 选项 |
|---|---|
| 体裁 | 短剧、影视 |
| 时长（要写剧本时） | 按剧情估一个（推荐）、先看方向再定；用户在输入框里填秒数 |
| 画幅 | 横屏 16:9、竖屏 9:16 |
| 模型版本 | Seedance 2.0、Seedance 2.5 |

- 用户选「其他」并输入内容时，按下面各项的规则处理（例如输入了别的比例就按他的；平台数字不同就请他说明）。
- 选项里已经写明了比例，用户选中就等于确认，**不用再回显确认**；用户自己输入了「横屏」「竖屏」这类没有比例的词时，仍按下面的规则补比例并回显。
- 题材（重生、犯罪、爱情等）不做成选项，用户给了就用，缺了在体裁之后用文字补问。

**文字问法**：没有选择工具时，把几项放在**同一条消息里，按顺序列出**。下面每项的规则，两种方式都适用。

**体裁**
> 这次是短剧还是影视？题材（比如重生、犯罪、爱情）如果你已经有想法，也可以一起告诉我。

- **体裁**指形式（短剧或影视），决定走哪一套剧本规则和摄影规则，所以固定要问（带了剧本也问）；用户带了成稿剧本时，问法换成「这份剧本按短剧还是影视来拍？」。
- **题材**指内容，用户给了就不问，缺了再问。

**画幅**
> 视频要横屏还是竖屏？具体比例是多少？

- 用户只说「横屏」，按 16:9；只说「竖屏」，按 9:16。并且把采用的比例回显给用户确认。
- 用户给了其他比例，按用户的。横竖方向也没说时，不要自己默认。
- 画幅会影响构图、站位、景别和走位方向，所以必须在分镜和资产之前定。

**模型版本**
> 用 Seedance 2.0 还是 2.5？

- 版本决定单次生成的时长上限和参考图的数量，数字见 `models.md`。
- 如果用户的平台数字和默认不一样，让用户说出实际的单次最长时长和最多图片数，按用户的来。

**时长**（只在要由你来写剧本时问：用户只给了主题、想法或梗概）
> 视频总时长大概多少秒？想自己定就在下面的输入框里直接填数字。

- **和体裁、画幅、版本放进同一个弹窗**，排在体裁后面、画幅前面。提问器的每个问题都要带选项，下面另有一个可以自己输入的框（「其他」）：时长的**选项不写具体秒数**，固定两个：「按剧情估一个（推荐）」和「先看方向再定」；重新问时把「和上次一样（××秒）」排在第一个。用户要自己定，就在输入框里填秒数。
- 提问器没有自己输入的地方，或者一次放不下四个问题时，时长改用文字问（放在同一条消息里，或者紧接着问），然后停下等回答。
- 用户选「按剧情估一个」时，按故事内容估一个时长，在交付剧本时写明估的是多少秒。选「先看方向再定」时，先给故事方向（第二节），用户选定方向后再问一次时长（这一次只问时长）。
- 用户这次已经说了时长，或者带了成稿剧本（时长由剧本决定），就不问。
- 拿到时长后按它写剧本：场次和动作节拍的数量、台词总字数都按时长定（台词约 4.5 字/秒，要给动作和反应留时间，见 `script-common.md`「台词时长」）；分镜阶段按它和模型版本的单段上限划片段。

问完之后：画幅和版本写进后面各阶段，不要在【整体概念】里重复写画幅和时长。

## 第二节　流程中的确认（必问）

**下表里的问题，到了对应的时机就必须问，没有一条是可选的附加动作。** 怎么问：

- **优先用提问选择工具（弹窗）**，每个问题 2–4 个选项，每项都允许自己输入（「其他」）；没有这类工具才用文字。
- **问完就停下，等用户回答**：提问是这一阶段交付的最后一步，和交付的正文在同一条回复里。没收到回答，不进入下一个阶段，也不替用户选。用户回答后照他选的做，不再另问一遍。
- **合并成一个问题的只有一处**：分镜交付后，「要不要改」和「接下来做什么」放在同一个问题里（原因见表后）。其他问题各自在出现的时机问；同一时刻碰巧有好几个（例如交付剧本时还有几处补充内容要确认），放进同一次调用。

| 时机 | 问题 | 选项 |
|---|---|---|
| 用户只给了主题或概念（没有人物和事件），第一节问完之后 | 按哪个方向写？ | 2–3 个一句话的核心想法，各写清谁想要什么、什么打破了平静；用户可以选「其他」自己写 |
| 你补充了用户没写的内容 | **常规补充**（服装细节、语气、动作节拍、外观默认）集中列出，一次问：「补充的这几处要沿用吗？」；**改动剧情、台词、人物关系，或有两种以上合理选法的补充**，每处单独一个问题 | 常规：都沿用；我要改其中几处。单独的：沿用；去掉 |
| **剧本交付后** | 剧本需要修改吗？ | 不改，继续做分镜；我要修改（只做剧本时换成「就这样，结束」） |
| **分镜（含镜头速览表）交付后** | 分镜需要修改吗？不改的话，接下来做什么？ | 不改，生成导演手册（推荐）；不改，只要提示词（资产和视频提示词，文字交付）；不改，到分镜为止；我要修改 |
| 用户直接从资产包、视频提示词开始，还没问过要不要手册时（开始前问） | 接下来要什么？ | 导演手册（整理成一个 HTML，含资产和视频提示词）；只要提示词（资产提示词和视频提示词，文字交付） |
| 用户确认之后发现矛盾或错误 | 发现……，要这样改吗？说明改哪里、为什么 | 按建议改；保持确认版 |
| 用户选了「我要修改」，或在「其他」里写了修改内容 | 改完后**再问一次**同一个确认问题 | 同上 |

- **分镜确认为什么要合并**：分两次问时，用户选了「不改，确认分镜」，agent 常常就此停住，不再问下一步。所以**交付分镜的最后一步就是弹出这个合并的问题**。
- **要导演手册还是只要提示词，每次都要问**：用户没有明说时，一定问一次，时机是**交付分镜时（和确认分镜一起问），不要在开头问**。用户说「继续做资产」「做视频提示词」不等于不要手册，不能跳过这个问题；用户直接从分镜之后的阶段开始时，在开始前问。
- **主题太空时问方向，不问「要不要生成剧本」**：能说出谁想要什么、发生了什么的，是梗概，直接写剧本；只有主题词或氛围（例如「亲情」「雨夜」），同一个主题能写出完全不同的故事，先给 2–3 个核心想法让用户选，选定后再写。方向要在体裁问完之后给（影视和短剧的写法不同）。
- 用户选「我要修改」，或在「其他」里写了内容：用文字问清改哪里（他已经写清楚的就直接改），改完再问一次同一个确认问题。
- 只做单个阶段时，把「继续做分镜」之类的选项换成「就这样，结束」。用户开头就说了要导演手册的，分镜确认的选项改成「不改，继续做导演手册；我要修改」。
- 问题里先说结果（交付了什么、改了什么），选项用动词开头；你推荐的放第一个，后面加「（推荐）」，不要写长篇理由。
- 构思有洞、场景图读不懂、平台数字和默认不一样时，也要先问用户，不要自己硬写（见 `script-common.md`「动笔前」、`principles.md` 第 12 条、上面第一节「模型版本」）。

**什么算问了、什么不算：**

> ✓ 弹窗：「剧本需要修改吗？」选项「不改，继续做分镜」「我要修改」，然后停下等回答。
> ✓ 没有弹窗工具时，用文字列出选项并停下：「剧本需要修改吗？1. 不改，继续做分镜　2. 我要修改（直接写要改哪里）」。
> ✗ 交付剧本后只在结尾带一句「剧本已完成，需要修改请告诉我」：没有给出选项，这不算提问。
> ✗ 环境里有弹窗工具，却用文字列选项代替弹窗：文字列选项只在没有弹窗工具时才算。
> ✗ 先问「分镜需要修改吗」，等回答后再另问「接下来做什么」：分镜这里必须合并成一个问题。
> ✗ 正文输出完就结束这一轮，该问的问题没问。
> ✗ 问了之后没等回答，自己选了一个继续往下做。

**不用问的情况只有这些：** 同一份作品里已经问过、用户已经回答的不再问（用户说过「这类默认都按你的来」，之后同类的常规补充不再问）；新的生成请求按第一节重新问；用户明说了的不再问（例如开头就说「根据这个剧本出完整的导演手册」「一路做到导演手册」，就是明说要手册，不再问手册的问题；体裁、画幅、模型版本照问）。除此之外，到了表里的时机就要问。
