# 提问规则：开始前先问，以及各阶段的确认

## 顺序

**体裁 → 画幅 → 模型版本。** 只问当前任务需要的，已经说过的不重复问。

| 任务 | 体裁 | 画幅 | 模型版本 |
|---|---|---|---|
| 只要剧本（要你来写） | 问 | 不问 | 不问 |
| 只要剧本（用户已带剧本，只是改） | 问（带剧本也问） | 不问 | 不问 |
| 分镜 | 问（带剧本也问） | 问 | 问 |
| 资产包 | 不问 | 问 | 问 |
| 视频提示词 | 问 | 问 | 问 |
| 导演手册 | 问（带剧本也问） | 问 | 问 |

同一个项目里问过的，后面沿用，不要再问。

**先判断用户给的是什么：**

- 用户给的是**故事梗概、想法或几句话的情节**，这**不是剧本**。任务要从剧本阶段开始。成稿剧本（有场次、动作、台词）才算「用户已带剧本」，但**带了成稿剧本也要问体裁**：体裁决定分镜和视频提示词用哪一套摄影规则，手册里也要填。不要因为故事已经有了，就当成只剩分镜或视频提示词。
- **体裁不能自己推断**：用户没明说「短剧」或「影视」时（带了剧本也一样），不要根据故事内容、时长、风格猜体裁，必须问。只做资产包时不问。
- **开头不问「做到哪一步」**：用户没说做到哪一步时，从他给的东西对应的阶段开始（只有故事，就从剧本开始），每个阶段交付后用确认问题带他往下走。要不要手册、还是只要提示词，**交付分镜时和确认分镜一起问**（见「其他提问」）。

## 怎么问

把需要问的几项**一次问完，按上面的顺序**，让用户一次回答。不要逐项拆成好几轮。

**有提问选择工具（弹窗选项）就用它，没有就用文字。**

- 把需要问的几项放进**同一次调用**，顺序是体裁 → 画幅 → 模型版本；只放当前任务需要的。
- 每一项都必须允许用户**自己输入**（例如「其他」）；工具不允许自由输入，或一次只能问一项，就改用下面的文字问法。
- 选项如下：

| 问题 | 选项 |
|---|---|
| 体裁 | 短剧、影视 |
| 画幅 | 横屏 16:9、竖屏 9:16 |
| 模型版本 | Seedance 2.0、Seedance 2.5 |

- 用户选「其他」并输入内容时，按下面各项的规则处理（例如输入了别的比例就按他的；平台数字不同就请他说明）。
- 选项里已经写明了比例，用户选中就等于确认，**不用再回显确认**；用户自己输入了「横屏」「竖屏」这类没有比例的词时，仍按下面的规则补比例并回显。
- 题材（重生、犯罪、爱情等）不做成选项，用户给了就用，缺了在体裁之后用文字补问。

**文字问法**：没有选择工具时，把几项放在**同一条消息里，按顺序列出**。下面每项的规则，两种方式都适用。

**体裁**
> 这次是短剧还是影视？题材（比如重生、犯罪、爱情）如果你已经有想法，也可以一起告诉我。

- **体裁**指形式（短剧或影视），决定走哪一套剧本规则和摄影规则，所以固定要问（带了剧本也问）；用户带了成稿剧本时，问法换成「这份剧本按短剧还是影视来拍？」。
- **题材**指内容，用户给了就不问，缺了再问。

**画幅**
> 视频要横屏还是竖屏？具体比例是多少？

- 用户只说「横屏」，按 16:9；只说「竖屏」，按 9:16。并且把采用的比例回显给用户确认。
- 用户给了其他比例，按用户的。横竖方向也没说时，不要自己默认。
- 画幅会影响构图、站位、景别和走位方向，所以必须在分镜和资产之前定。

**模型版本**
> 用 Seedance 2.0 还是 2.5？

- 版本决定单次生成的时长上限和参考图的数量，数字见 `models.md`。
- 如果用户的平台数字和默认不一样，让用户说出实际的单次最长时长和最多图片数，按用户的来。

## 其他提问：确认和选择（同样优先用弹窗）

整个流程里**向用户提任何问题**，都优先用提问选择工具（弹窗）；没有这类工具才用文字。规则和上面一样：待确认的几项放进**同一次调用**（工具一般最多 4 个问题），每个问题 2–4 个选项，每项都允许自己输入（「其他」）。

常见的几处：

| 什么时候 | 问题 | 选项 |
|---|---|---|
| 用户只给了主题或概念（没有人物和事件），体裁、画幅、版本问完之后 | 按哪个方向写？ | 2–3 个一句话的核心想法，各写清谁想要什么、什么打破了平静；用户可以选「其他」自己写 |
| 剧本交付后 | 剧本需要修改吗？ | 不改，继续做分镜；我要修改 |
| 分镜（含镜头速览表）交付后，**一次问完** | 分镜需要修改吗？不改的话，接下来做什么？ | 不改，生成导演手册（推荐）；不改，只要提示词（资产和视频提示词，文字交付）；不改，到分镜为止；我要修改 |
| 用户直接从资产包、视频提示词开始，还没问过要不要手册时（开始前问） | 接下来要什么？ | 导演手册（整理成一个 HTML，含资产和视频提示词）；只要提示词（资产提示词和视频提示词，文字交付） |
| 你补充了用户没写的内容（台词、动作、人物细节） | 补充的「……」要沿用吗？每处补充一个问题 | 沿用；去掉 |
| 用户确认之后发现矛盾或错误 | 发现……，要这样改吗？说明改哪里、为什么 | 按建议改；保持确认版 |

- **分镜交付后，确认分镜和「接下来做什么」放在同一个问题里一次问完**，不要先问「分镜需要修改吗」、等用户确认后再另问一次：分两次问时，用户选了「不改，确认分镜」，agent 常常就此停住，不再问下一步。**交付分镜的最后一步就是弹出这个问题；没弹就不算交付完。**
- **要导演手册还是只要提示词，每次都要问**：用户没有明说时，一定问一次，时机是**交付分镜时（和确认分镜一起问），不要在开头问**。用户说「继续做资产」「做视频提示词」不等于不要手册，不能跳过这个问题；用户直接从分镜之后的阶段开始时，在开始前问。用户明说了要或不要的才不问：**开头就说了「根据这个剧本出完整的导演手册」「一路做到导演手册」这类话，就是明说要手册，不再问**（体裁、画幅、模型版本照问）。
- **主题太空时问方向，不问「要不要生成剧本」**：能说出谁想要什么、发生了什么的，是梗概，直接写剧本；只有主题词或氛围（例如「亲情」「雨夜」），同一个主题能写出完全不同的故事，先弹窗给 2–3 个核心想法让用户选，选定后再写。方向要在体裁问完之后给（影视和短剧的写法不同）。「要不要根据这个主题生成剧本」不是真正的选择，不要问。
- 用户选「我要修改」，或在「其他」里写了内容：用文字问清改哪里（他已经写清楚的就直接改），改完**再问一次**同一个确认问题。
- 只做单个阶段时，把「继续做分镜」之类的选项换成「就这样，结束」。
- 用户已经回答过的不再问（例如开场就说了「做完分镜直接生成手册」）。
- 问题里先说结果（交付了什么、改了什么），选项用动词开头；你推荐的放第一个，后面加「（推荐）」，不要写长篇理由。

## 之后

- 画幅和版本问完后，写进后面各阶段，不要在【整体概念】里重复写画幅和时长。
- 交付分镜时，用同一个问题问「分镜需要修改吗，接下来做什么」：导演手册、只要提示词、到分镜为止、我要修改（每次都要问，见上面「其他提问」）。
