# 人物资产（人物四视图）

为每个人物写一份给文生图模型用的提示词，生成的图作为视频提示词里 `@图N` 的参考，锁定外观。

## 输入

- 剧本交接结构里的**人物信息表**：身份、年龄、职业或处境、外观特征、说话方式（见 `script-common.md`）。
- 用户已有的人物图：直接复用，不重做；只补缺的。
- 剧本没写外观时，按身份和年龄推出一个朴素的默认外观补全，**在交付说明里告诉用户这是补的**；提示词里只写外观本身，不写「制作默认」这类说明（见 `principles.md` 第 11 条）。
- 已经问过画幅和模型版本（见 `ask-before-start.md`）。人物四视图有自己的版式，不受视频画幅限制。

## 版式

**人物四视图 = 三视图 + 面部近景，共四格，每格都有脸。**

- 三视图：正面、90° 侧面、背面，**全身**，三个视图里都有脸，是同一个人。
- 第四格：面部近景（含肩颈和领口）。
- 浅灰色纯色背景；人物站姿自然，双臂自然下垂，手中不持物；图上没有任何文字。

## 提示词的块

```
【版式】
【人物身份】
【皮肤状态】
【服装】
【光影关系】
【镜头质感】
【情绪】
【反向限制】
```

写成一份连续的提示词交付，块名保留。

**【版式】**：写四格的排列顺序（正面、侧面、背面、面部近景），声明四格是同一个人，五官、发型、肤色、体型、服装完全一致，写站姿、背景、无文字。

**【人物身份】**：年龄、气质、身高体型。
- **年龄要有锚**：直接写「外表就是 40 岁左右，不显老」这类句子；25 岁左右的人物还要防止被画老或画得过于成熟，写出年轻感的可见特征（脸颊饱满、眼神清澈、皮肤紧致）。
- 衰老和体型细节写轻，用「较浅」「轻微」，不要用「明显」「很深」。
- 面相要写成具体的脸型、眉形、眼形、鼻、唇，不只写「面相温柔」这类词。

**【皮肤状态】**：分两层写。
1. **通用底层（每个人物都写）**：真实皮肤质感、细腻毛孔、可见皮肤纹理、肤色有冷暖变化、哑光质感、非假白。
2. **身份推导层（随人物变化）**：先看年龄、职业、生活环境，再推出对应的痕迹，并**写明部位**。例如工地工人：长期户外作业的古铜偏红肤色、额头较浅的抬头纹、鼻翼与嘴角轻微暗沉、下巴和两颊的胡茬根部、粗糙的手和指甲缝里少量灰色污渍。

**【服装】**：逐件写，材质写具体，新旧和磨损写清楚。污渍写**颜色、部位、面积**，并写出不想要的相邻状态（「没有泥浆」）；容易混淆的材质加「不是××」（「帆布材质，不是牛仔布」）。

**【光影关系】**：柔和均匀的自然漫射光，面部高光柔和，阴影自然过渡，皮肤哑光质感，四格光影一致。

**【镜头质感】**：真实摄影棚人像质感，原相机感，RAW，胶片质感。三张全身图清晰锐利；面部近景格轻微浅景深，眼睛对焦清晰。（不写「抓拍感」，它和三视图的中性要求冲突。）

**【情绪】**：一句话，神情和目光。

## 【反向限制】

用「以下内容一律不要出现：」开头。

**图像底（所有图像提示词固定写，人物和场景都用）**：文字、乱码、logo、水印、过度锐化、HDR 感、局部对比度增强、青橙对比色调、高饱和、CG 感、概念图感、游戏原画感、插画、没有来源的发光、画面杂乱。

**人物图追加**：过度磨皮、塑料皮肤、肤色均匀、毛孔消失、油光发亮、美颜过度、网红脸、偶像化、四格人物不一致、换脸、服装不一致、背景杂乱；有年龄锚的人物加「显老」或「显小」「成熟感」等对应的一项。

追加只有两种情况：确有这个风险，或者**实际出过这个问题**。不要把不会出现的东西列进去。

## 人物状态变体

人物在剧情里发生**持续**变化（摘下头盔或帽子、脱外套、受伤、浑身是泥），而且跨 2 个镜头以上时，单独出一张**状态版**：还是同一个人，只改状态层。要写清：

- 脱下来的东西**去哪了**（拿在手里、夹在腋下、放在桌上）。
- **脱掉之后本体的样子**（发型被压扁、额前有压痕、只剩内搭）。
- 伤和污损的位置、面积、新伤还是旧伤。

原因：资产图锁定的是「这个东西长什么样」，不是「它必须在身上」。不写清的话，模型可能把图里戴着的头盔和提示词里夹在怀里的头盔叠加成两个。这个说法来自 manju-laoli 用户的一次实测反馈，我们没有复现过。只跨一个镜头的变化，用文字在分镜里写清楚即可。

## 示例

`examples/character-worker-40.md`：40 岁工地工人（实测一个样本，效果良好）。

## 说明

「皮肤两层」「年龄锚」「写轻」「污渍写颜色部位面积」这些写法来自对两个人物的出图实测，**样本很少，没有做过系统对照**。示例里【版式】沿用实测过的原话「人物设定四格图」，没有跟着改名：「人物四视图」是这类图在手册和文档里的叫法，版式由后面写明的四格排列决定。
