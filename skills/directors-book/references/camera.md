# 摄影

分三部分：**基础**两个体裁都读；**影视加强**只在体裁是影视时读；**运镜词表**两个体裁写运动镜头时都查。

## 基础（短剧和影视都读）

1. **先情绪后技术**：每个镜头，先答「观众此刻该感到什么」，再选光影、构图、运镜。
2. **观看先于术语**：说清观众接近谁、何时知道什么、注意力怎样转移、结束时留下什么。
3. **摄影机的角度、运动、速度、光线都要有叙事动机和可见结果。** 不把「电影感」当成完整的设计。
4. **先导演，后提示词；先可演的动作，后情绪形容词。**
5. **多人场面，没有共享的空间关系，不进入镜头细化。** 先确定谁在哪里（场景资产的空间布局），再设计镜头。
6. **关系镜头优先于互不相干的人像**；镜头数由节拍、信息密度和表演呼吸决定，没有最低镜数。
7. **相邻镜头共享可核对的出口和入口状态**，关键道具写明初始、变化、结果三个状态，并且在它出现的每个镜头里都写位置（见 `storyboard.md`）。
8. **背景不是静止布景**：每个可见的角色有独立的动作、注意力和错峰的反应，而且从属于主焦点，不抢戏。背景里走动的人要写清画面方向和与主角的关系（同向、迎面、横穿），不能只写目的（「赶去」「回家」）。
9. **运动要解释画面里发生了什么**：靠近、离开、升降、变焦，写框内关系怎样改变，不用参数名代替。
10. **时间要给动作、辨认、台词和反应留空间**，不能用快切或吞词掩盖冲突。
11. **第一次生成可以探索；第二次必须带着诊断，一次只改一个关键变量。**
12. **默认无背景音乐**：只做台词、音效、环境声；用户要音乐才加。
13. 不写「变形宽银幕」，不用片名、人名、摄影师名当锚点（见 `principles.md`）。
14. **运镜不同时叠加，可以先后接续**：同一时刻只做一种运动，不要同时要求推、拉、摇、移（火山引擎《Seedance 2.0 提示词指南》的「运镜写法」：同时要求几种运镜会让画面不稳定）。但一个镜头里可以**先后**换运动，节奏是「运动 → 停住 → 下一个运动」，并且换的那一下要有剧情触发：例如摄影机后退跟随人物往前走，人物突然停住、愣了一下，摄影机随之停住，再缓慢推近他的脸。一个镜头里最多接两段运动；中间那一下停顿要写出来；不要无缘无故连换。
15. **轴线（短剧和影视都用）**：两人对话、或人物看向某个目标时，在他们之间定一条轴线，同一场戏的机位都留在轴线同一侧，这样每个镜头里谁在画面左边、谁在右边保持不变。要越线，用合法办法：中轴镜头、摄影机在画面里移动越线、切到完全不同的画面；越线后，在提示词里写明左右已经对调。
16. **先写调度底稿，再拆镜头**：每场戏先用文字写一份俯视调度：固定物的位置（引用场景资产的布局句）、人物分段站位和路线、轴线、每个镜头的机位（在哪个参照物旁、朝哪个参照物看、在轴线哪一侧）。每个镜头里谁在画面左右、脸朝哪边、往画面哪里走，都从这份底稿推出来。底稿是写分镜用的，不进视频提示词；复杂场景可以另出走位图（见 `asset-scene.md`）。
17. **运镜不要带偏走向，也不要拍出参考图的范围**：人物横向走动，才用横移跟拍；人物朝纵深走（远离或走近镜头），用背后跟随、固定机位或摇镜，并写出画面里的变化（背对镜头、身影变小、朝画面上方哪个参照物走去）。镜头要去的角度如果在场景参考图里看不到（母版和场景多机位都没有），模型只能自己补景、甚至再造一栋楼；换一个参考图里看得到的角度，或者先补一张那个角度的场景图。

## 影视加强（体裁是影视时再读）

1. **简版美学设定**：在视频提示词的【摄影与影调】块里，用两三句写色调、光的方向、构图倾向，不另建文档。
2. **主场景法**：先有一个包含完整内容的主镜头，其余过肩、中景、特写是填进去的「砖块」；反应镜头要和对方镜头同焦距同尺寸。（轴线和调度底稿已移到基础第 15、16 条，两个体裁都用。）
3. **主光方向对应情绪**：正面光偏扁平；3/4 前光自然；侧光戏剧、对比强；3/4 背光神秘有深度；背光有轮廓感、剪影。想让画面「显得暗」，用背光，不是降曝光。
4. **动机光**：每束光都要有可解释的来源，并写明衰减方向；没有来源的光就是 AI 感。
5. **摄影支撑要选定**：手持、肩扛、稳定器、轨道、固定。选手持时，写明晃动的来源、方向、强弱、触发和收稳的节点，不要只写「手持」。
6. 器材和镜头：用焦距感描述（例如「接近 40mm」「平视」），不用变形镜头，不用片名和人名。
7. **少用固定镜头**：影视体裁默认用运动镜头讲戏（斯坦尼康跟随、缓推、轻微环绕、跟拍，见下面的「运镜词表」），尤其是人物走动、进出场、情绪推进的地方。**普通的对话正反打可以用固定镜头，数量不限**；其他地方的固定镜头留给需要停顿的时刻：宣判、凝视、沉默、一句关键台词之后。
8. **对话也可以按剧情和氛围用运镜**：正反打不是只能固定。根据这场戏的情绪选：压力逐渐升高，用很慢的缓推贴近说话的人；两人关系对峙或试探，用轻微环绕或在两人之间缓慢横移；一方崩溃或得知真相，用邵氏变焦或希区柯克变焦（只用在那一下）；平静温情的闲聊，用轻微的手持呼吸感或斯坦尼康缓慢跟随。运镜不同时叠加（可以按基础第 14 条先后接续），机位仍留在轴线同一侧，运镜的选择要说得出理由（这一刻观众该感到什么，见基础第 1 条）。

## 运镜词表

**怎么用**：写分镜时，先按情绪和调度从表里选运镜。镜头速览表的「机位与运动」一列写名称，方便人看；**提示词正文里写「名称 + 画面写法」**，再补上起点、终点（用场景里的参照物）和速度（缓慢、约 3 秒内）。有名字的组合运镜（例如希区柯克变焦）算一种运镜；要在一个镜头里先后接两种运镜，按基础第 14 条写出停顿和触发。

模型认得标准运镜词（推、拉、横移、固定、特写等，火山引擎《Seedance 2.0 提示词指南》），但**有名字的专业运镜只写名字，常常做不出来**，必须把画面里发生的事写出来。下表的「画面写法」是给模型看的，照着改写进正文。

| 运镜 | 画面写法（写进提示词） | 注意 |
|---|---|---|
| 缓推 | 摄影机缓慢向前移动靠近人物，前景的物体从画面两侧滑出，人物逐渐变大 | 是摄影机在动，有前后景的视差 |
| 拉远 | 摄影机缓慢后退，人物逐渐变小，周围的环境一点点进入画面 | 拉出来的区域要在场景参考图里看得到 |
| 变焦推近 | 摄影机位置不动，画面放大到人物的脸，前后景之间没有位移 | 和缓推不同：只是放大，没有视差；要视差就写缓推 |
| 横移 | 摄影机沿着人物行走的方向平行移动，人物在画面里位置基本不变，背景从一侧滑向另一侧 | 只用于人物横向走动（基础第 17 条） |
| 摇镜 | 摄影机原地转向，画面从 A 处扫到 B 处 | 写清从哪个参照物摇到哪个参照物 |
| 背后跟随 | 摄影机在人物身后一两步，跟着他往前走，人物背对镜头，前方的目标逐渐变大 | 往纵深走时用 |
| 斯坦尼康跟随 | 摄影机像被人稳稳端着贴身跟随，画面平滑没有颠簸，随人物转身、上下台阶自然起伏，距离始终保持一两步 | 可在人物前方倒退着拍，也可在身后；写清在哪一侧 |
| 升降 / 摇臂 | 摄影机从低处缓慢升高，越过前景的花坛（或栏杆），露出后面的整个院子 | 升到哪里、露出什么要在参考图里看得到 |
| 轻微环绕 | 摄影机绕人物缓慢转过四分之一圈到半圈，人物始终在画面中央，身后的背景跟着转换 | 环绕会拍到人物和场景的其他侧面，参考图里没有的地方模型会自己补；15 秒内不要转整圈；不要和复杂动作叠加 |
| 迈克尔·贝环绕 | 摄影机贴近地面仰拍，绕人物快速转半圈，人物始终在画面中央、大小不变，身后的天空和建筑快速掠过，常配合人物起身或转头 | 速度快，容易变形；人物动作保持简单 |
| 邵氏变焦（急推） | 画面先保持一个较宽的取景，随后在约半秒内猛地放大到人物的脸并停住，摄影机位置不动 | 时间要短；常配合人物猛然转头或瞪眼 |
| 希区柯克变焦 | 摄影机向后退的同时镜头不断放大，人物在画面里的大小始终不变，身后的背景却越来越远、透视被拉伸，有眩晕感（反过来：摄影机前推同时缩小画面，背景逼近） | 最常被要求、也最容易失败的运镜；一定要按这种机械的写法写，不能只写名字 |
| 甩镜 | 摄影机快速横甩，画面拉出强烈的动态模糊，模糊中切到下一个画面 | 用作转场；会带来切换，相邻镜头的左右关系照样要对上 |
| 手持 | 摄影机由人扛着，画面有轻微的呼吸般晃动，人物停下时晃动收稳 | 写明晃动的来源和幅度（影视加强第 5 条） |
| 子弹时间 | 人物和飘起的物体先定格在空中，随后摄影机绕着定格的画面缓慢转过半圈 | 只写名字常常只出慢动作；要写「先定格、再环绕」 |
| 一镜到底 | 整个片段不切镜头，摄影机连续跟随人物从 A 处走到 B 处 | 路线必须在场景里走得通，经过的地方要有参考图 |

这张表的效果描述来自电影常识和几份公开的 AI 视频运镜指南（Runway 的运镜提示词指南，Gigwise、Atlabs、besovideo 等的实测文章），用自己的话改写，**没有在 Seedance 上逐条验证**。用户可以补充想要的运镜。

## 说明

这些规则来自对多个摄影相关 skill 和书籍提炼内容的整理，已按「只借思路、不拷原文」改写，**没有做过系统的对照实验**。
