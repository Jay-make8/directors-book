# 交付前自检

按阶段小节逐项核对。缺项就补，补完再交付。核对时要真的回头看产出，不要凭印象打勾。

## 剧本

- [ ] 动笔前写出了一两句话的核心想法和戏剧性前提（谁想要什么、什么打破平静、核心问题）。
- [ ] 用户只给了主题或概念、没有人物和事件时，先弹窗给了 2–3 个核心想法让他选，没有直接写完整剧本，也没有问「要不要生成剧本」。
- [ ] 有交接结构：人物信息表、场景信息表、各场次；每场有场次头、人物目的、动作节拍和台词、**结尾状态**。
- [ ] 交付后用提问选择工具问了「剧本需要修改吗」（环境没有才用文字）；自己补充的内容逐项问了是否沿用。
- [ ] 全稿体例统一：中文场号制，场次头是「第N场　内外景　地点　时段」，动作行以「△」开头，台词行是「角色（语气）：台词」，没有混用别的写法。
- [ ] 剧本里没有镜头术语（特写、POV、切、叠化、「我们看到」），没有镜号，没有生成提示词。
- [ ] 动作都是摄影机拍得到、演员演得出的；没有「想」「回忆」「意识到」这类内心描述；只写了常见动作，细微表情没有写。
- [ ] 每一场至少有一个动作节拍，不是纯对白。
- [ ] 用「所以／但是」读相邻节拍，没有只能用「然后」连接的地方；转折写成了「谁做了什么」。
- [ ] 冲突在升级，没有原地重复，也没有跳跃。
- [ ] 台词带语气，语气不超过 3 个词；遮住人名能分辨是谁在说；没有注水的寒暄。
- [ ] 台词字数对得上场次时长（约 3.5–6 字/秒）。
- [ ] 称呼的变化有事件支撑，同一关系阶段的称呼保持稳定。
- [ ] 人物的穿戴、随身物品、外观特征，在人物信息表和各场次之间一致，没有凭空出现、消失或自相矛盾的东西；场景信息表里的关键道具和场次里的动作对得上。
- [ ] 场与场之间的过渡承载了新信息，下一场的开头接得上上一场的结尾状态。
- [ ] 用户自带的剧本，没有被擅自改台词、事件或人物；发现的硬伤只是报告。
- [ ] 短剧：写了故事契约（目标与反对、因果升级、方向性转折、兑现、结尾状态）；钩子在前 3 拍内，是具象画面；世界观融进了行动；结尾写成了确定状态。
- [ ] 影视：人物靠压力下的选择揭示；对手比主角强；对白有潜文本，没有写在鼻子上；解说没有变成互相告诉对方都知道的事。

## 分镜

- [ ] 每个镜头都有标题行：`镜头号｜内景或外景｜时间段｜景别`，用全角竖线。
- [ ] 镜头号全片连续（后面的片段接着前面的编号），时间段每个片段从 0 秒起。
- [ ] 时间段连续、不重叠；每个片段的总时长在所选版本的上下限内。
- [ ] 没有一个镜头被拆在两个片段里。
- [ ] 做过合镜检查：相邻镜头是否满足五条合并条件；不合并的，有没有写明理由。
- [ ] **每个镜头的六项都「够」**（镜头、人物位置和走位、表情的可见变化、手和道具、台词、环境里在动的东西，标准见 `video-prompt.md` 的表）；确实不适用的项，在交付说明里逐条列出，没有悄悄跳过；每个片段的镜头正文平均不低于约 35 字/秒。
- [ ] 每句台词都写了语气（括号里不超过 3 个词，不能省）。
- [ ] 台词字数和时长对得上（约 3.5–6 字/秒）；写不下的已经缩短台词。
- [ ] 相邻镜头的出口和入口状态能对上；关键道具写了初始、变化、结果。
- [ ] 关键道具在它出现的**每个镜头**里都写了位置（在谁的哪一侧、桌面哪个位置）；上一镜头没动过的，下一镜头开头重述了位置；拿起、放下写了手和落点；是拿在手里还是放在桌上写清了。
- [ ] 走动的人物都有起点、路径、终点，落到了画面位置。
- [ ] 空间布局是引用场景资产的那一句，没有重写。
- [ ] 跨镜头、跨片段，人物的穿戴和手里的东西前后一致（对过人物信息表和上一个镜头的出口状态）。
- [ ] 分镜里人物、道具、场景物件的叫法，和剧本、场景信息表一致（剧本写台灯，分镜不能擅自改成吊灯）；确实要改，先问用户。
- [ ] 交付后用提问选择工具问了「分镜需要修改吗」；用户确认后才问接下来要什么（导演手册还是只要提示词）。
- [ ] 有一张片段划分表（段落、场景、镜头、总时长、需要的参考图）。
- [ ] 每个片段有镜头速览表（镜号、内外景、景别、机位与运动、画面要点、台词、时间）；表和正文一致，没有正文里没有的内容；台词列只写「无」或「谁说、几个字」，没有抄原文。
- [ ] 台词原文从分镜起只在【分镜】里出现一次（剧本是源头，不算）；速览表、【声音】里没有重复。

## 资产包

- [ ] 提示词里没有写给用户看的说明（「制作默认」「这是我补的」之类），这些放在交付说明里。
- [ ] 每个人物一份人物四视图提示词，块齐全：版式、人物身份、皮肤状态（两层）、服装、光影关系、镜头质感、情绪、反向限制。
- [ ] 人物有年龄锚，衰老和体型细节写得轻；污渍写了颜色、部位、面积。
- [ ] 反向限制用「以下内容一律不要出现」开头，有图像底，只追加了必要的项。
- [ ] 每个场景按档位出图：简单场景只出母版，常规场景出母版加场景多机位，复杂场景再加走位图；次要场景没有出场景多机位。
- [ ] 空间事实只写了一次：布局一句话、入口、固定物、年代与地域、空气；后面都是引用。
- [ ] 母版七个块齐全，含主机位 A；光影和镜头质感里有光学柔化、远景偏软、不要亮橙轮廓光、不要青橙。
- [ ] 场景多机位和走位图的提示词开头写了「根据@图1（场景母版）……」。
- [ ] 场景多机位是 2×2 共 4 格；第 1 格是主机位 A；其余机位按空间类型选；影调沿用母版；标注用数字加图外对照表。
- [ ] 走位图只给复杂场景；线稿；有方向、固定物、人物路线、机位和轴线；注明不是实测图。
- [ ] 场景图里没有人物、人影、动物。
- [ ] 持续变化跨 2 个镜头以上的场景或人物，出了状态版。
- [ ] 有一张资产编号表（编号、名称、用途）。
- [ ] 资产里的外观、穿戴和剧本的人物信息表一致，没有凭空加减（帽子、背的包、手里的东西）。
- [ ] 资产提示词里没有写全片统一的 `@图N`；场景多机位、走位图的提示词里提到母版时写 `@图1`。

## 视频提示词

- [ ] 块齐全：整体概念、参考素材绑定、（影视可选：摄影与影调）、分镜、声音、反向限制。
- [ ] 【整体概念】里没有时长、画幅、模型版本；空间布局写出了场景资产那一句的原文，没有只写「沿用场景资产的布局」。
- [ ] 【参考素材绑定】角色一行、场景一行；场景一行里主图、多机位、走位各自写清；`@图N` 按本片段的上传顺序从 1 连续编号（角色在前、场景在后），每个片段重新编号；附了「本段上传顺序」。
- [ ] 全篇用中文全角标点（音效的半角 `<>` 除外）；提示词里没有「主机位」「母版」「场景多机位」这类资产阶段的内部术语。
- [ ] 每句台词都写了语气（角色名后的括号里，不超过 3 个词，不能省），台词原文没有出现在【声音】里；台词说完后没有复述台词里的字，也没有回头补写这句话怎么说的。
- [ ] 每个镜头的六项都「够」（标准见 `video-prompt.md` 的表）；不适用的项已在交付说明里列出；平均低于约 35 字/秒就回头补，补的是看得见的内容，不灌水。
- [ ] 情绪转折点的镜头（认出、崩溃、决定、告别）写了 3 个以上先后出现的可见变化，没有只写「呼吸断半拍」「神情平静」。
- [ ] 镜头中途有变化的，都写了触发点；每个镜头只用一种运镜（没有先平移再推近这类叠加）。
- [ ] 表情用自然语言写；只有写不出来的才补了 AU，且不超过一两处。
- [ ] 【声音】写了环境声、人物近声、特殊声源，并说明是否配乐（默认无）；每个音效用 `<>` 括起来，按物理声源写；只有用户要音乐时才用（）写音乐。
- [ ] 【反向限制】有「以下内容一律不要出现」开头，有视频底，追加的项确有风险。
- [ ] 抽查：随机挑三个形容词，问「这能被画出来吗」；画不出的换成具体动作。
- [ ] 数字（时长、图片数量）来自 `models.md` 或用户给的，两个版本没有混用。

## 导演手册

- [ ] 用户没明说要不要手册时，在**剧本和分镜都确认之后**问过「接下来要什么：导演手册，还是只要提示词」，没有在开头问；用户说继续做资产或视频提示词，没有被当成不要手册；用户开头就说了要完整导演手册的，没有再问。
- [ ] 四个阶段都做完，分镜经用户确认后才整理成 `handbook.json`。
- [ ] `handbook.json` 里的 `shots` 和用户确认过的分镜一致，没有重新润色；台词原文只在 `shots` 里出现，`sound` 里没有重复。
- [ ] 各块的内容里没有再写块名（脚本会自动加）。
- [ ] 每个镜头都有 `camera`、`summary`、`lines`，和正文一致；`lines` 没有抄台词原文。
- [ ] 每个段落用到的资产都列在 `assets` 里；资产提示词在手册里只出现一次（集中在「资产提示词」一节）。
- [ ] 没有手写【参考素材绑定】和 `@图N`：`assets` 里列清每个段落用到的资产，必要时用 `use` 只带部分图，编号由脚本生成。
- [ ] 把 `script` 和 `shots` 跟用户确认过的版本对一遍（标点形式除外）；有不一致的地方，都已告诉用户并得到同意，没有擅自改。
- [ ] 运行了 `scripts/build_handbook.py`，没有错误；读过全部警告，能改的改了。
- [ ] 生成的是脚本输出的 HTML，没有手写或改过 HTML；文件名是 `项目名_导演手册.html`。
- [ ] 告诉了用户文件位置、怎么打开（用浏览器打开），以及每个提示词右上角有复制按钮。
- [ ] 手册顺序是剧本 → 分镜 → 资产提示词 → 视频提示词，视频提示词（第一段、第二段……）在最后。
- [ ] 没法运行脚本时：输出了同结构的 Markdown，并明确告诉用户这次没有生成 HTML。
