# 交付前自检

按阶段小节逐项核对。缺项就补，补完再交付。核对时要真的回头看产出，不要凭印象打勾。

## 剧本

- [ ] 动笔前写出了一两句话的核心想法和戏剧性前提（谁想要什么、什么打破平静、核心问题）。
- [ ] 要由你来写剧本的，开始前问过总时长（和体裁、画幅、版本同一个弹窗，排在体裁后面；选项是「按剧情估一个」「先看方向再定」，不写秒数，用户在输入框里填；提问器没有输入框时用文字问），剧本的场次、节拍和台词量按这个时长写。
- [ ] 这是新的生成请求时，体裁、时长、画幅、版本重新问过（即使同一个对话里前面问过），每个问题把上次的选择排在第一个、标了「（上次）」。
- [ ] 用户只给了主题或概念、没有人物和事件时，先弹窗给了 2–3 个核心想法让他选，没有直接写完整剧本，也没有问「要不要生成剧本」；这几个方向避开了第一反应，各带一个推不出来的具体细节和一句开场画面。
- [ ] 有交接结构：人物信息表、场景信息表、各场次；每场有场次头、人物目的、动作节拍和台词、**结尾状态**。
- [ ] 交付剧本的同一条回复里问了「剧本需要修改吗」（弹窗，或没有弹窗时用文字列出选项），问完停下等回答，没有只写一句「需要修改请告诉我」；自己补充的内容问了是否沿用：常规补充集中问一次，改动剧情、台词、人物关系的单独问（`ask-before-start.md` 第二节）。
- [ ] 全稿体例统一：中文场号制，场次头是「第N场　内外景　地点　时段」，动作行以「△」开头，台词行是「角色（语气）：台词」，没有混用别的写法。
- [ ] 剧本里没有镜头术语（特写、POV、切、叠化、「我们看到」），没有镜号，没有生成提示词。
- [ ] 动作都是摄影机拍得到、演员演得出的；没有「想」「回忆」「意识到」这类内心描述；只写了常见动作，细微表情没有写。
- [ ] 每一场至少有一个动作节拍，不是纯对白。
- [ ] 用「所以／但是」读相邻节拍，没有只能用「然后」连接的地方；转折写成了「谁做了什么」。
- [ ] 冲突在升级，没有原地重复，也没有跳跃。
- [ ] 台词带语气，语气不超过 3 个词，写的是声音和姿态，不是潜台词解释；遮住人名能分辨是谁在说；没有注水的寒暄；不是通篇一来一回的短句。
- [ ] 台词字数对得上场次时长（慢速 3–4、正常 4–5、偏快 5–6 字/秒）。
- [ ] 每场结束时的局面和开始时不同；每场至少有一处只属于这个人的动作习惯或物件。
- [ ] 结尾留下一个画面、一个问题或一种心情，不是一个道理；没有「避开的写法」里的泛称人名、温情万能配方、抖机灵结尾、对称翻转、主题贴纸（`script-common.md`）。
- [ ] 交付前在内部冷读过一遍（哪里走神、哪里没看懂、哪里是剧情替人说话），没有把这一遍展示给用户。
- [ ] 称呼的变化有事件支撑，同一关系阶段的称呼保持稳定。
- [ ] 人物的穿戴、随身物品、外观特征，在人物信息表和各场次之间一致，没有凭空出现、消失或自相矛盾的东西；场景信息表里的关键道具和场次里的动作对得上。
- [ ] 场与场之间的过渡承载了新信息，下一场的开头接得上上一场的结尾状态。
- [ ] 用户自带的剧本，没有被擅自改台词、事件或人物；发现的硬伤只是报告。
- [ ] 短剧：写了故事契约（目标与反对、因果升级、方向性转折、兑现、结尾状态）；钩子在前 3 拍内，是具象画面；世界观融进了行动；结尾写成了确定状态。
- [ ] 影视：开头几秒有一个「不太对」的日常画面；人物靠压力下的选择揭示；对手比主角强；对白有潜文本，没有写在鼻子上；解说没有变成互相告诉对方都知道的事。

## 分镜

- [ ] 每个镜头都有标题行：`镜头号｜内景或外景｜时间段｜景别`，用全角竖线。
- [ ] 镜头号全片连续（后面的片段接着前面的编号），时间段每个片段从 0 秒起。
- [ ] 时间段连续、不重叠；每个片段的总时长在所选版本的上下限内。
- [ ] 没有一个镜头被拆在两个片段里。
- [ ] 做过合镜检查：相邻镜头是否满足五条合并条件；不合并的，有没有写明理由；每一次切都有理由（换空间、换时间、换视角、换信息层级、情绪断点、节奏和精彩程度）；镜头数由剧情和精彩程度决定，没有为凑数多切，也没有为少出参考图少切或把反打改成同一个方向。
- [ ] 每个镜头先定了（内部）必须看懂什么，关键动作在正文里写清楚了，没有被手指、衣角、风这类细节淹没；镜头、人物位置和走位、手和道具、台词写清楚了，表情和环境运动按需写（标准见 `video-prompt.md` 的表）；没有为凑字补写；正文里只有画面，没有走位推导和导演解释。
- [ ] 每句台词都写了语气（括号里不超过 3 个词，不能省）。
- [ ] 台词字数和时长对得上（慢速 3–4、正常 4–5、偏快 5–6 字/秒，超过 6 只用在争吵、慌乱、抢话）；说不完的先延长镜头或在自然停顿处拆开，没有擅自删改确认过的台词。
- [ ] 相邻镜头的出口和入口状态能对上；关键道具写了初始、变化、结果。
- [ ] 关键道具在它出现的**每个镜头**里都写了位置（在谁的哪一侧、桌面哪个位置）；上一镜头没动过的，下一镜头开头重述了位置；拿起、放下写了手和落点；是拿在手里还是放在桌上写清了；同一件道具只有一个，拿起后原位置变空。
- [ ] 有正反面的道具（手机、照片、屏幕）：先定了用途、谁拿着、朝向、对准什么，画面里看到哪一面是按机位推出来的，没有自相矛盾（例如摄影机和手机都朝房子，却写看到手机背面）。
- [ ] 走动的人物都有起点、路径、终点，落到了画面位置。
- [ ] 写镜头前先写了调度底稿（固定物、人物分段站位、轴线、每个镜头的机位）；每个镜头的机位都在轴线同一侧，谁在画面左、谁在右和上一个镜头一致；越线的写明了左右对调。两人以上的戏，人物绑了场景实物（靠哪个实物站）；站位是剧情先定的，机位跟着站位走，「面对镜头」「背对镜头」是推出来的结果，没有单独先定；左右是按摄影机在两人连线哪一边推的，没有只看摄影机朝哪拍。调度底稿用方位（东南西北加依托的实物）定站位，没有把方位写进提示词；还没有图时，站位标了「待图片核验」。
- [ ] 点名做可见反应的人都在这一镜景别框得住的范围里（中近景约一人、中景两三人、全景全员）；要求不入画的人有可信的去处（离开、被遮挡、在摄影机背后）（`camera.md` 基础第 19 条）。
- [ ] 单人镜头（近景、特写）写了人物偏画面哪一侧、脸朝哪边、视线看向哪边，和前后镜头的左右关系一致。
- [ ] 机位写了参照物（在哪个物体旁、朝哪个物体看），参照物是场景里固定的东西或本镜位置已写清的人，不是「来路」「刚才的位置」；写成「画面左侧是……」的只有这个景别看得见的东西；近景和正反打写了人物身后是什么，和场景布局对得上；正文里没有「轴线」「靠近镜头 / 观众的一侧」；有运动的写了起点和终点；往纵深走的镜头没有用横移跟拍；镜头要拍到的方向都有场景参考图，缺的列成了要补的图，没有为了不补图改镜头。
- [ ] 方向以画面为准（画面左侧、画面右侧、靠近或远离镜头），没有单独写「朝右后方」「往左前方」。
- [ ] 背景里走动的人群、路人写了画面方向和与主角的关系（同向、迎面、横穿），没有只写目的（「赶去」「回家」）。
- [ ] 每个片段的第一个镜头按「镜头 → 开场状态 → 动作与台词 → 背景」写，开场状态写了每个在场人物的位置、朝向、姿态和手里的东西；朝向和视线跨镜头不变，变了的写成了动作；离开画面的写了从哪一侧出画。
- [ ] 同一场戏里入画的人没有凭空消失：全景、中景里写了他在哪；特写、单人近景里没有点名不入画的人，而是用镜头里人物的视线方向（看向画面哪一侧外）交代方位；画面外说话的写了声音从哪一侧来；后面才开口的人从开场就在。
- [ ] 片段接缝放在天然切点（切特写、遮挡、甩镜、动作匹配、声音桥），没有拆在动作或台词中途，上一段结尾没有提前做下一段的主要动作；片段划分表里写了每个接缝用的切点。
- [ ] 写调度底稿前读过场景图：每个动作在图上有走得通的路线，每个机位在参考图里拍得到（`principles.md` 第 12 条）。
- [ ] 景别按人物在画面里的大小写；有台词、关键动作或表情的镜头没有用远处的机位。
- [ ] 切到物品特写或插入镜头时，没有点名画面外的人，用看得见的部分（一只手从画面哪一侧伸进来）交代方位，或写「画面里只有……」；和上一个镜头里人相对物品的方位一致。
- [ ] 影视体裁：走动、进出场、情绪推进用了运动镜头（对话正反打用固定镜头可以，也可以按情绪用缓推、轻微环绕等运镜）；用了专业运镜的，写了「名称 + 画面写法」（`camera.md` 运镜词表），没有只写名字。
- [ ] 空间布局是引用场景资产的那一句，没有重写。
- [ ] 跨镜头、跨片段，人物的穿戴和手里的东西前后一致（对过人物信息表和上一个镜头的出口状态）。
- [ ] 分镜里人物、道具、场景物件的叫法，和剧本、场景信息表一致（剧本写台灯，分镜不能擅自改成吊灯）；确实要改，先问用户。
- [ ] 做过提示词回读校对（`readback.md`；只有一个人、只朝一个方向拍、没有走动的段落可以留到视频提示词阶段）：盲读者只拿到镜头正文和固定物坐标；调度图和调度底稿一致，文字没有自相矛盾，每个镜头朝的方向都有图（缺的列成了要补的图）；对不上改的是正文，不超过三轮；三轮还不行已经停下问用户；交付分镜时附了 `--layout` 生成的调度图页面。
- [ ] 交付分镜的同一条回复里，用一个问题问了「分镜需要修改吗，接下来做什么」（选项见 `ask-before-start.md` 第二节），问完停下等回答；没有拆成两次问，也没有替用户选了往下做。
- [ ] 有一张片段划分表（段落、场景、镜头、总时长、需要的参考图）。
- [ ] 每个片段有镜头速览表（镜号、内外景、景别、机位与运动、画面要点、台词、时间）；表和正文一致，没有正文里没有的内容；台词列只写「无」或「谁说、几个字」，没有抄原文。
- [ ] 台词原文从分镜起只在【分镜】里出现一次（剧本是源头，不算）；速览表、【声音】里没有重复。

## 资产包

- [ ] 提示词里没有写给用户看的说明（「制作默认」「这是我补的」之类），这些放在交付说明里；也没有「不要为了……」「不限定……」「实际仍在……」这类修补解释句。
- [ ] 每个人物一份人物四视图提示词，块齐全：版式、人物身份、皮肤状态（两层）、服装、光影关系、镜头质感、情绪、反向限制。
- [ ] 人物四视图【版式】第一句是固定的排列句：四格横向排列，从左到右依次为正面全身、90°侧面全身、背面全身、面部近景；不是 2×2；图上不标格号。
- [ ] 人物有年龄锚，衰老和体型细节写得轻；污渍写了颜色、部位、面积。
- [ ] 反向限制用「以下内容一律不要出现」开头，有图像底，只追加了必要的项；反打、俯视图、角度图只写骨架里那几句、不加整段反向限制；宫格的场景多机位、走位图用骨架里允许标签的版本。
- [ ] 人物四视图：正面、侧面、面部近景五官一致；没有要求背面全身有脸。
- [ ] 每个场景按档位出图：简单场景只出母版，常规场景出母版、反打、俯视图，再加镜头要用的角度图，复杂场景再加走位图；出图顺序是母版 → 反打（只传母版）→ 俯视图和角度图（传母版和反打）→ 走位图（传俯视图）；每张单图，没有用宫格（2.0 额度不够时除外）。
- [ ] 反打的背景按空间事实写了母版背后那一面的入口、门窗、固定物；母版、反打、角度图都记了朝向（交付说明里的《方向图对照表》，导演手册里的 `facing`）。
- [ ] 角度图是镜头真要用的方向，不是为了凑数；镜头要用的方向没有漏出图（一切为剧本和剧情服务）。
- [ ] 空间事实只写了一次：布局一句话、方位（内部用）、入口、固定物、年代与地域、空气；后面都是引用。布局句写的是实物之间的关系，没有画面左右（画面左右只在母版【空间分层】按主机位 A 写一次）。母版出图后和布局句不一样的，已按母版改了这一句。
- [ ] 母版七个块齐全，含主机位 A；去 AI 感按题材选：剧情片加了低饱和、光学柔化、远景偏软、不要亮橙轮廓光、不要青橙；展示类按参考图保持该清楚的细节清楚，先定了最值得看的部位，没有统一调灰调软。
- [ ] 俯视图提示词是一句话「根据@图1（场景母版）生成这个空间的俯视图」，没有把布局句、家具清单抄进去；俯视图出来后，对照它核对了分镜里的站位和机位，也对照母版和用户参考核对了俯视图本身；母版里看不到的区域当作未知，没有当成已验证的结构。
- [ ] 角度图每个方向一张，和母版、反打同方向的不出；用宫格时（额度不够）写了「共 N 格，不多不少」；每个机位写了在哪、朝哪拍、画面里看到什么（必要时什么不入画）；标签用 V1、V2……；《机位对照表》（V 编号、在哪朝哪、用于哪几个镜头）写在交付说明里。
- [ ] 走位图只给复杂场景；在俯视图上叠加人物路线、轴线和机位小箭头，俯视图本身没有改；交付说明里写清字母各是谁、这是示意不是实测图。
- [ ] 场景图里没有人物、人影、动物。
- [ ] 持续变化跨 2 个镜头以上的场景或人物，出了状态版。
- [ ] 有一张资产编号表（编号、名称、用途）。
- [ ] 资产里的外观、穿戴和剧本的人物信息表一致，没有凭空加减（帽子、背的包、手里的东西）。
- [ ] 资产提示词里没有写全片统一的 `@图N`；反打里母版是 `@图1`；俯视图、角度图里母版是 `@图1`、反打是 `@图2`；走位图里俯视图是 `@图1`。

## 视频提示词

- [ ] 块齐全：整体概念、参考素材绑定、（影视可选：摄影与影调）、分镜、声音、反向限制。
- [ ] 【整体概念】里没有时长、画幅、模型版本；空间布局写出了场景资产那一句的原文（实物之间的关系，没有画面左右），没有只写「沿用场景资产的布局」。
- [ ] 【参考素材绑定】每张图一句话：它是什么、只参考什么（画面里只有一个某某、角度图不是分镜、走位图的线条和标注不进画面、上一段最后一帧按接缝当首帧或状态参考）；补充说明最多一两句，没有重复正文已写的位置、左右、手的动作；`@图N` 按本片段的上传顺序从 1 连续编号（角色在前、场景在后），每个片段重新编号；附了「本段上传顺序」。
- [ ] 全篇用中文全角标点（音效的半角 `<>` 除外）；提示词里没有「主机位」「母版」「场景多机位」「角度图」这类资产阶段的内部术语。
- [ ] 摄影机换到两人连线另一边的镜头，明写了新的左右；这一段的反向限制没有「人物左右位置互换」。
- [ ] 影视体裁每个镜头有「光线：」段；有明确光源的，光从画面哪一侧来是按这一镜摄影机的位置和朝向推的（看光源在摄影机哪一边），没有照抄上一镜，也没有套用人物左右的结论；阴天、雨天这类漫射光没有硬写方向，写的是上方柔光和哪边被遮挡稍暗；【摄影与影调】里只写光源绑在哪个场景实物、冷暖软硬，没有写画面左右。
- [ ] 风、烟、水、纱帘写了来源、方向、先带动什么再带动什么；全景、远景写了人物在画面里有多大。
- [ ] 上一段已经生成、用户给了画面或反馈的，这一段的开场状态按实际画面写，没有按计划接。
