# 短剧剧本专属规则

先读 `script-common.md`。这里只写短剧特有的。体例和影视相同：中文场号制，动作行用「△」（见 `script-common.md`）。

## 故事契约（动笔前写，一段话）

短剧篇幅短，先把下面五项想清楚：

1. **目标与反对**：人物想让什么在结尾前发生；谁或什么在阻止，凭什么能阻止。
2. **因果升级**：写成选择链——因为 A，人物做了 B；B 引来反制 C；C 迫使人物放弃旧办法或付出更大的代价。
3. **方向性转折**：人物原来的计划、理解或关系位置，在哪一刻不再适用。
4. **兑现**：观众为什么不觉得这只是在拖延？这个故事自己给出的局部结果是什么。
5. **结尾状态**：写成确定的事实（谁作了什么决定、谁知道什么、人在哪里、拿着什么），不只写「悬念：他是谁」。

## 开场

- **钩子是第一拍的具象画面**，不是一句神秘的台词；它要在**前 3 拍内**出现，并且连着本故事的目标，否则只是装饰。
- **世界观信息融进行动，不要放在开头铺垫**。短剧常见的错误，是把电影式的世界观铺垫搬到开头。
- **开场自检（六要素）**：异常事件、即时目标、致命规则、现实阻力、身份或信息的反转、未完成的答案。只用来检查开场够不够抓人，**不是填空公式**；以因果为主。

## 节奏

- **先兑现一个局部结果，再留下新压力**；开放结尾不等于没写完。
- 台词和动作交替；每场至少一个动作节拍。

## 说明

这些规则整理自几个短剧相关 skill 和一个抖音讲解的思路，已用自己的话改写，**没有做过系统对照实验**。
