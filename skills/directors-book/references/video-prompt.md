# 视频提示词

每个**片段**（导演手册里叫「段落」）写一份提示词。一个片段是一场戏里的一个或几个镜头，时长在所选版本的单次上限内（见 `models.md`）。

## 块与顺序

```
【整体概念】
【参考素材绑定】
【摄影与影调】（影视体裁可选，短剧默认不加）
【分镜】
【声音】
【反向限制】
```

写完整份提示词再交付，每个块都要有，不要省略块名。

## 【整体概念】

只写**这个片段的背景故事和场景简述**。

- 不写时长、画幅、模型版本（这些开始前已经问过，写进了后面各阶段）。
- 场景里写**空间布局**时，把场景资产里那一句布局**原样复制进来**（去掉「以主机位A的画面为准」这类内部说明），不要自己改写成另一种左右关系。**不要写「沿用场景资产的布局」这类指代**：模型看不到资产文字，这样写等于没写。例：✗「以主机位A画面为准，柜台横贯中部……」，✓「柜台横贯中部……」。
- 篇幅两三句话到一小段，说清谁、发生了什么、在哪里。

## 【参考素材绑定】

**每张图一行，写清它是什么、参考什么、不参考什么**（火山引擎官方提示词指南：每个素材写明编号和用途，只参考一部分时写明参考哪一部分）：

```
@图1 是男人的外貌参考：四格是同一个人的不同角度，只参考长相、发型和服装，画面里只出现一个男人。
@图2 是丽姐的外貌参考：四格是同一个人的不同角度，只参考长相、发型和服装，画面里只出现一个丽姐。
@图3 是这个场景的主图：参考空间布局、材质和光线。
@图4 是这个场景的四个角度（V1–V4）：只用来理解空间结构，不是分镜，不要按格子顺序生成镜头；图上的 V1–V4 标注不要出现在画面里。
@图5 是这个场景的俯视走位示意图：只参考人物的站位和路线；图上的线条、箭头和字母不要出现在画面里。
@图6 为首帧：本段从这一帧开始（上一段视频的最后一帧）。
```

- 只写类别（「角色：男人@图1」「场景：多机位@图4」）不够：模型可能把四宫格当成分镜按顺序生成，把四视图当成四个人，把走位图上的线条画进画面。
- 没有走位图、没有首帧的片段，就不写那一行。一个片段里有两个场景时，把「这个场景」换成场景名。
- **上一段的最后一帧要写成首帧**（官方写法「图片 N 为首帧」）；平台有首帧上传位的，优先传到首帧位。
- **`@图N` 是这个片段里的上传顺序，从 `@图1` 开始连续编号，每个片段重新编号**：先角色（按出场顺序），再场景（主图、多机位、人物走位）。同一张图在不同片段里编号可以不同；不要沿用全片统一的编号。
- 之前片段出现过的人物和场景，这个片段仍要上传同一张图，并按本段的顺序重新编号。
- 这一块之后，另附一句「本段上传顺序：图1 …；图2 …」，让用户照着上传（导演手册里由脚本生成，不用手写）。
- 每张图只承担一个主要职责。

## 【摄影与影调】（影视体裁可选）

两到四句，写这个片段的影调和摄影：色调、主光方向和光的来源、摄影支撑（手持要写晃动的来源和幅度，人物停下时收稳）、焦距感。规则见 `camera.md` 的「影视加强」。短剧默认不加这个块。

例：
> 影调低饱和，以冷灰色漫射光为主，暖色只出现在地平线和窗内的灯光里。主光是画面左后方低角度的夕阳余光，不在物体边缘形成亮橙色轮廓光。摄影为手持，晃动来自操作者的呼吸和脚步，幅度小，人物停下时收稳；焦距感接近 40mm，平视。

## 【分镜】

每个镜头先写一行标题，再写正文：

```
镜头1｜内景｜0-5秒｜中景
正文
```

- 标题行四项用全角竖线 `｜` 分隔：镜头号、内景或外景、时间段、景别。
- 时间段连续、不重叠；每个片段的总时长不超过所选版本的上限。
- **镜头号全片连续**（后面的片段接着前面的编号数），**时间段每个片段从 0 秒重新起算**。
- 景别写档位词：大远景、远景、全景、中全景、中景、近景、特写、大特写，必要时加过肩等。
- **景别按人物在画面里的大小定**，不是按拍到了多少建筑：机位远到人物只是小小的身影，就写远景或大远景，不要写全景。**有台词、有关键手部动作或表情的镜头，不用远处的机位**，否则模型会为了让人看得清，把人挪近、甚至再造一面墙。
- 时间段用**整数秒**。Seedance 2.0 只认镜头序号，2.5 认整数秒的时间戳；这个标题格式两个版本都适用，不用改（见 `models.md` 的「两个版本怎么读镜头和时间」）。

**正文默认写成一段，顺序固定：镜头运动 → 人物动作与台词 → 背景。** 镜头描述很长或多人走位时，可以拆成三行：「镜头：」「人物：」「背景：」。

**人物动线**：每个走动的人写起点、路径、终点，落到画面位置，并写步态和距离变化（见 `principles.md`）。

**往纵深走要写成画面里的变化**：人物远离或走近镜头时，写「背对镜头」「身影逐渐变小」「朝画面上方的茶桌走去」这类看得见的变化，运镜用背后跟随、固定或摇镜；**横移跟拍只用于人物横向走动**，否则人会被带着横着走。镜头不要拍到场景参考图里看不到的区域（见 `camera.md` 基础第 17 条）。

**台词嵌入动作**，格式：`角色（语气）+ 关联动作 + 说：“台词”`。

- 语气放在角色名后面的括号里，不超过 3 个词，用动词或短语，不写长句。**不能省**：即使后面的动作已经表现了情绪，也要写语气词（例如「低声」「迟疑」「抢话」）。
- 台词和一个看得见的动作绑在一起；声音类词（沙哑、发颤）写在语气里，不单独写进画面描写。
- 两人声音重叠时，写出重叠的秒数，写在后一句台词的**前面**（例如「老周在女儿说到最后两个字时就开口，两人重叠约 0.3 秒，说：“回——”」）。
- **台词说完，不要复述台词里的字，也不要回头补写这句话是怎么说的**：语气、表情、动作都放在台词前面。火山引擎《Seedance 2.5 提示词指南》的常见问题指出，台词后面复述再追加语气、表情、动作描述，容易让模型生成字幕。✗「说：“太像了。”说到“像”字时声音发颤。」✓「老周（声音发颤）说：“太像了。”」台词之后接新的动作可以，例如「说完，他转身走开」。
- 台词原文**只在这里写一次**，【声音】里不再重复。

**镜头中途有变化**：把变化嵌在对应动作后面，写出触发点（谁做了什么、走到哪）。例如「B 走到第五步时，镜头开始缓慢拉远，把追上来的 A 也收进画面」。只有一个运动时，开头一句写完即可。

**运镜不同时叠加，可以先后接续**（见 `camera.md` 基础第 14 条）：同一时刻只写一种运动；一个镜头里要换运动，写成「运动 → 停住 → 下一个运动」，并写出触发点。例：「摄影机在他前方后退跟随，他沿石板路往前走；走到第三块石板时他突然停住，眉头皱起，摄影机随之停住，停顿半秒后缓慢推近到他的脸。」一个镜头最多接两段运动。

**表情**：先用自然语言写可见的变化；写不准、写不出来时，再加 AU 编号辅助（见 `performance.md`）。

## 【声音】

写四样：

1. 环境声（这个空间里一直有的声音）。
2. 人物近声（脚步、衣料摩擦、呼吸）。
3. 特殊声源（例如手机听筒里的声音，音量和质感）。
4. 是否配乐：**默认无配乐**，用户要才写。

**符号**（火山引擎官方提示词指南的特殊字符规范：音乐用圆括号，音效用尖括号，台词用花括号，字幕用方头括号）：

- **每个音效用半角尖括号 `<>` 括起来**，按物理声源写：谁或什么、在哪、发出什么声音。例：`<远处机械低沉的轰鸣>`、`<雨点砸在铁皮屋顶上>`。「氛围感音效」这类说法模型做不出来。
- **只有用户要音乐时**，才用全角圆括号写音乐，例如「（背景中播放低沉的大提琴独奏）」。
- 默认无配乐时，不加括号，直接写「不要背景音乐，只保留环境声、动作声和台词」。
- 台词暂时仍按上面的格式写在【分镜】里（中文引号），不改成花括号；是否改用花括号待对比测试后再定。

例：

> 环境声：<远处机械低沉的轰鸣>，<风吹过脚手架的呼呼声>，<脚手架金属偶尔的轻响>。人物近声：<老周沉重的脚步声>，<衣料摩擦声>，<压着的呼吸声>。特殊声源：女儿的声音从手机听筒里传出，音量小，略带电流质感。不要背景音乐，只保留环境声、动作声和台词。

台词本身不在这里写。

## 【反向限制】

用「以下内容一律不要出现：」开头，后面接一串，用顿号分隔。

**视频底（固定写）**：配乐、字幕、夸张的哭喊、面部僵硬、嘴唇无故动作、换脸、服装变化、人物左右位置互换、可读的文字或乱码、水印。

**按需追加**，只有两种情况：
- 这个片段确有这个风险。例如有年龄锚的人物加「年龄变化、显老」；画面里有屏幕或招牌时加「屏幕和招牌上的可读文字或乱码」；有走动时加「运动方向反转、人物瞬移、穿过家具或门」。
- **实际出过这个问题**。

不要把根本不会出现的东西列进去，也不要重复同一类意思。

## 每个镜头写到什么程度

镜头正文是模型唯一能读到的画面描述，**写得太简，画面就由模型自由发挥**（见 `principles.md` 第 1 条）。下面六项，**每个镜头的每一项都必须「够」**：不要求写满，但不能缺。确实不适用的（例如这个镜头没人说话、画面里没有道具），可以不写，但自查时要明确它是「不适用」，不能是「忘了」。

| 项 | 「够」的最低标准 |
|---|---|
| 1. 镜头 | 写出景别、机位（在哪个参照物旁、朝哪个参照物看，留在轴线同一侧）和运动（固定，或怎么动；不同时叠加，先后接续时写出停顿和触发）；有运动时写出起点、终点和触发点，以及画面里因此发生了什么。读完能画出取景框。 |
| 2. 人物位置和走位 | 画面里每个看得见的人：位置（画面哪一侧、前景后景）、朝向、姿势；走动的人再写起点、路径、终点和步态（快慢、轻重）。**单人镜头（近景、特写）也要写**：人物偏画面哪一侧、脸朝画面哪一侧、视线看向画面哪一侧，并和前后镜头的左右关系一致（同一条轴线，见 `camera.md` 基础第 15 条）。 |
| 3. 表情和情绪 | 每个有戏的人（说话的、被说的、被打动的）写 1–2 个**可见变化**：眼、眉、嘴、喉、下巴、呼吸、肩，哪里在动。**情绪转折点的镜头**，关键人物写 3 个以上**先后出现**的变化，并写触发点。「平静」「克制」「沉默片刻」「神情复杂」不算，读完不看情绪词，也要知道脸上哪里在动（见 `performance.md`）。远景、全景里看不清脸，就写身体的变化。 |
| 4. 手和道具（含人和物品的相对位置） | 画面里的关键道具：位置和状态（正反面、开合、在手里还是在桌上）；有拿起、放下、翻面时，写用哪只手、落在哪里（见 `storyboard.md`）。**切到物品特写或插入镜头时**，写清人在哪里（「两人都在画面左侧外，只露出男人的右手」或「画面里没有人」），并和上一个镜头里人相对物品的方位一致：上一个镜头两人都在物品左边，特写里就不能变成物品两边各一个人。 |
| 5. 台词 | 嵌在动作里，格式见上；每句台词都有语气（不超过 3 个词）和一个同时发生的可见动作。 |
| 6. 环境里在动的东西 | 每个镜头至少一项持续或变化的、看得见或听得见的东西：光的变化、雨、风、烟、背景里的人、门铃、脚步、钟声。要和场景设定一致。**背景里走动的人（人群、路人）写清往哪走**：用画面方向写（往画面左侧、朝镜头走来、往画面深处走），并写和主角的关系（和主角同向、迎面走来、从主角身后横穿），不能只写他们要去干什么。✗「大量赶去看升旗的人」（只写了目的，模型可能让人群和主角反着走）；✓「大量看升旗的人和男主同方向，往画面深处走」。 |

**长度参考**（来自我们几次实测的产出，不是平台限制，也没有验证过「写得更长画面就更好」）：整份提示词约 1000 字 / 15 秒；镜头正文大约每秒 35–50 字。一个 15 秒片段的镜头正文只有 300–450 字（约 20–30 字/秒），通常是漏了第 2、3、6 项，最常漏的是第 3 项表情。低于约 35 字/秒，手册脚本会警告。**不要灌水**：补的必须是画面里看得见的内容，不是形容词。景别越紧，动作越少、描述越细。

**情绪转折点的镜头要写得最细。** 认出、崩溃、决定、告别这类镜头是观众记住的地方，不能比过渡镜头写得还短。写 3 个以上**先后出现**的可见变化（眼、眉、嘴、喉、手、呼吸，哪一侧先动、动多大），并写出触发点。例：

> ✗ 老陈的食指停住，眼睛固定在刻痕上，呼吸断半拍，随后抬眼看向空着的街门。
> ✓ 老陈的食指停在刻痕外侧，指腹轻轻下压；他的眼睛先收紧，眉间随后皱起，喉结滚动一次，呼吸断了半拍，嘴唇张开一线又抿住；他慢慢抬眼，目光从怀表移向空着的街门，眼眶边缘泛红，没有流泪。

（这个例子只演示写法，不是要求每次都写成这样。）

## 写法细节

- 全篇用**中文全角标点**（，。：；？！“”（）），`@图N`、数字、英文缩写照常。唯一的例外是音效的尖括号，用半角 `<>`（官方写法）。
- **方向一律以画面为准**：左右写「画面左侧」「画面右侧」，远近写「靠近镜头」「远离镜头」或「画面下方」「画面上方」。不要单独写「朝右后方」「往左前方」这类方向：模型不知道是谁的右后方，常常直接理解成画面右边。
- 提示词里**不要出现资产阶段的内部术语**：主机位A、母版、场景多机位、档位。要交代镜头朝哪个方向，直接写画面里的方向，例如「从楼道里看向防盗门」，不要写「保持主机位A方向」。
